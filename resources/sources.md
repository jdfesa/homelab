## Adding Sources

Para cada incorporación registrar título descriptivo, URL o enlace al archivo local, tipo de material, tema/uso, fecha y estado de revisión. Añadir autor, versión o fecha original sólo si se conocen; no inventarlos.

Mantener un archivo por documento y enlazarlo, sin duplicar PDFs en cada VM. Un módulo puede citar este catálogo cuando corresponda; sus pasos de instalación deben indicar qué se adaptó, comprobó y ejecutó realmente. Revisar el material de terceros por separado antes de publicar el repositorio.
